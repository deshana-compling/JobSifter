About the Role

We are looking for an AI Application Engineer to build and deploy software applications that incorporate modern artificial intelligence capabilities. You will primarily work on backend services and APIs while integrating AI and external language model services into production-oriented applications.

The ideal candidate has strong Python development skills and practical experience building backend systems.

Day to day responsibilities:

- Design and develop backend applications using **Python**.
- Build and maintain **REST APIs** for internal and external applications.
- Develop backend services using frameworks such as FastAPI.
- Integrate third-party APIs and AI services into software applications.
- Containerise applications using **Docker**.
- Use **Git** and collaborative software development workflows.
- Work with databases and persistent application data.
- Deploy and maintain applications in cloud environments.
- Implement appropriate error handling, validation, logging, and testing.
- Collaborate with software engineers and AI specialists to deliver production-ready AI features.
